# Android phone testing

[Download FarmingStar 1.0.0](https://github.com/uhm-j4ke/FarmingStar/raw/main/betas/FarmingStar-1.0.0-Android-TEST.apk). This is the new offline, test-signed APK; please report device test findings.

The signing identity differs from the older 0.4.0 beta. Export your save from the old app before uninstalling it; then install this version and import your save. Do not uninstall your only saved copy first.

The versioned GitHub release also includes this APK, Windows, macOS and standalone HTML. The older beta remains archived here.
