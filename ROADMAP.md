# Development roadmap

## Current game — 1.0.0

Chicken farming and controller controls are implemented in the shared `index.html`; see [DEVELOPMENT_TRACKER.md](DEVELOPMENT_TRACKER.md) for verification. The current game includes expanded mirror customisation, themed menus, map controls, TV forecasts and isolated development tools. The user has now authorised 1.0.0 packaging and a public GitHub release; see RELEASE_TEST_REPORT.md for current build status.

## Next milestones

- Complete the user’s Android 1.0.0 device check and address any new findings.
- Keep future app releases and the production website in sync through the native release workflow.
- Verify controller mappings, focus, reconnect and activities on physical hardware and each native platform.
- Measure performance on actual Android devices; cloud browser measurements do not certify device frame rate.

## Future expansion

- Additional animal farming: cows, sheep, suitable shelters/care and animal products. Only chickens are implemented in the current browser expansion.
- iOS/iPadOS: a separate target when explicitly requested, with appropriate signing/provisioning.
- More seasonal events, furniture, cooking interactions and exploration, while retaining save reliability and progression safeguards.
